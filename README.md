## Funktionalitet
- Skapa team members (UX, frontend, backend)
- Skapa uppgifter
- Tilldela uppgifter
- Status: new → in progress → finished
- Radera färdiga uppgifter
- Filtrera och sortera

## Teknisk stack
- React
- Firebase Firestore
- Vite
- JavaScript
- CSS
